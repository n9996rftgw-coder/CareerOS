# Example operating rules

- Preserve originals and append corrections with their source and date.
- Match every claim to the evidence store. Missing evidence is a gap.
- Keep employer identity, dates, personal contribution and team metrics distinct.
- Confirm summary wording and evidence references before using it.
- Preserve the latest approved CV structure; agree layout changes explicitly.
- Confirm submissions, sent messages and historical dates before logging them.
- Read the canonical live record before a connector write and verify the changed cells.
- Local files are snapshots when a live canonical Sheet is configured.
- Keep personal records and credentials outside the code repository.
- No automatic applications, external sending or recurring work is configured.
